> 3.97″ touchscreen for local dashboard in [[Garden Monitor]].

## Specs

- **Model:** ASX00039
- **Screen:** 3.97″ 480×800 touch display
- **Extras:** IMU, digital microphone, Arducam connector
- **Compatible with:** Arduino GIGA R1 WiFi
- **Rating:** 4.7/5 (69 reviews)
- **Purchased:** Dec 12, 2025

## ⚠️ Compatibility Note

This shield is designed for the **Arduino GIGA R1 WiFi** board specifically. Options:
- Purchase a GIGA R1 WiFi to use this display
- Use the [[ESP Display 5in]] as the primary display instead
- Use [[Raspberry Pi 5]] with an HDMI monitor as an alternative

## Role in Project

- Local real-time dashboard showing soil moisture, temp, humidity, air quality
- Touch interface for manual pump override and history viewing
- Could display [[Arduino Nicla Vision]] camera snapshots
