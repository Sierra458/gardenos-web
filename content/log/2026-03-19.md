## 📝 Notes

**Software stack for Phase 1:**
- Arduino IDE 2.x → upload sketch to Mega
- Python 3 + pyserial → serial reader on Pi 5
- CSV file → data logging (can import to Excel/Sheets/Grafana later)

**Key code decisions:**
- 9600 baud serial — reliable, fast enough for 5-second readings
- 10-sample averaging on Mega — smooths electrical noise
- JSON format — easy for Python to parse, human-readable in Serial Monitor
- Separate calibration constants at top of Arduino code — easy to update after testing
