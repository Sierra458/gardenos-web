# Plant Profiles — Houston South Wall

> Watering and care reference for all plants in the [[Garden Monitor]] system.
> See [[Outdoor Watering System]] for the technical irrigation design.

---

## Zone 1 — Spearmint (Mentha spicata)

| | |
|---|---|
| **Container** | Single pot |
| **Sun** | 6–7 hrs (may benefit from afternoon shade in peak summer) |
| **Water need** | HIGH — keep soil consistently moist |
| **Frequency** | Daily in Houston summer heat |
| **Soil** | Rich, moist, well-draining potting mix with perlite |
| **Hardiness** | USDA 4a–11b · Perennial in Houston |
| **Houston behavior** | Goes into "hibernation" in extreme summer heat, rebounds in fall |
| **Common issues** | Rust (fungal — keep foliage dry), slugs/snails |
| **Tips** | Mulch pot to reduce evaporation · Water at base only · Pinch for bushier growth |

---

## Zone 2 — Lavender (Lavandula sp.)

| | |
|---|---|
| **Container** | Rectangle pot (3 plants) |
| **Sun** | 6+ hrs — loves full sun |
| **Water need** | LOW — drought-tolerant, hates wet feet |
| **Frequency** | Once a week MAX when established, possibly less |
| **Soil** | Sandy, fast-draining, slightly alkaline · Mix with coarse sand and perlite |
| **Hardiness** | Varies by type · 2–3 year lifespan in Houston |
| **Best varieties for Houston** | Sweet Lavender, Fern Leaf, French, Spanish |
| **Houston behavior** | Struggles in humid summers — foliage can turn black if wet |
| **Common issues** | Root rot (overwatering), fungal blackening, rust |
| **Tips** | Mulch with GRAVEL not organic mulch · Water at base only · Don't over-fertilize · "If you think it needs water, wait until tomorrow" |

---

## Zone 3 — Citronella (Pelargonium citrosum)

| | |
|---|---|
| **Container** | Single pot |
| **Sun** | 6+ hrs, benefits from afternoon shade in peak heat |
| **Water need** | MODERATE — let top inch dry between waterings |
| **Frequency** | Every 2–3 days in Houston summer |
| **Soil** | Well-draining potting mix with perlite/sand and compost |
| **Hardiness** | USDA 9–11 · Bring indoors before frost |
| **Houston behavior** | Handles heat and humidity reasonably well |
| **Common issues** | Root rot from overwatering, gets leggy without enough sun |
| **Tips** | Pinch tips for bushier growth · Fertilize biweekly in growing season · Toxic to pets |

## Zone 4 — Potato Tower

| | |
|---|---|
| **Container** | Tower (wire cage + soil/straw layers) |
| **Sun** | 6+ hrs but monitor soil temperature |
| **Water need** | HIGH — consistent moisture critical for tuber formation |
| **Frequency** | Every 1–2 days during tuber formation, 1–2 inches per week overall |
| **Soil** | Loose, loamy, well-draining · Layer with straw for moisture retention |
| **Growing season** | Houston spring: plant Jan–Feb, harvest by May · Fall: plant late Aug–Sep |
| **⚠️ Critical** | Soil temp > 75°F = tubers stop forming. Houston summers are too hot. |
| **Common issues** | Flea beetles, aphids, blight, heat stress |
| **Tips** | Insert PVC pipe in tower center for deep watering · Mulch top with straw · Consider shade cloth · Stop watering when vines yellow (curing phase) · Use drip irrigation |
